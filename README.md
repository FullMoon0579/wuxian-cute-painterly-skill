# 无线搞可爱风绘图风格 Skill

用于批量生成与维护“无线搞可爱风”插画的 Codex skill。

## 内容

- `SKILL.md`：调用说明、风格目标、批量工作流、提示词结构与硬性排除项。
- `references/style-bible.md`：形状、表情、配色、材质、构图与批量变化规则。
- `agents/openai.yaml`：Codex 中显示的名称、简介与默认调用模板。

## 调用

在 Codex 中使用：

```text
$wuxian-cute-painterly
```

也可以直接说：“使用无线搞可爱风……”。

## 核心约束

- 以参考素材的共同视觉语法为准：几何大色块、粗颗粒数字手绘、低到中饱和、简洁背景。
- 忽略素材中的水印、平台标识、账号名与其他固定标记。
- 每张图都必须进行肢体一致性检查，禁止重复手臂、重复手、额外手指、融合或悬空肢体、镜像肢体等问题。
